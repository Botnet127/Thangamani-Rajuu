# Thangamani Raju — Cybersecurity Analyst

Personal portfolio. Deploy on Vercel, then attach a custom domain.

## Deploy

1. Push this repo to GitHub (public).
2. Import it at [vercel.com/new](https://vercel.com/new).
3. Framework: Vite. Build command and output are already set in the project.
4. Project Settings → Domains → add `yourname.com` and `www.yourname.com`.
